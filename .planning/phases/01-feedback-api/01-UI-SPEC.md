## New Components Required (Phase 1)

### 1. Section Page (`_buildSectionPage`)

Each section occupies one PageView page and contains all its questions stacked vertically.

Structure:
```
Column
  SectionHeaderRow (icon + section name + "N de M")
  Divider
  Expanded > SingleChildScrollView
    for each question in section:
      QuestionBlock (question text + LikertScale)
      SizedBox(height: 24)
  SizedBox(height: 16)
  NavigationRow (Back / Next or Submit)
```

- Section header: `AppTextStyles.heading3`, left-aligned, `AppColors.textPrimary`
- Section counter ("2 de 6"): `AppTextStyles.label`, right-aligned, `AppColors.textSecondary`
- Section icon: Material icon, 20px, `AppColors.secondary`
- Divider after header: `AppColors.divider`
- Navigation row height: 48px buttons, full width using `Row` with `Expanded`

### 2. Section Progress Indicator (`_buildSectionProgress`)

Replaces the individual-question progress dots. Shows overall section completion.

Structure: `LinearProgressIndicator` inside a `Container` with 8px top margin.
- Height: 6px (`minHeight: 6`)
- Track color: `AppColors.divider`
- Fill color: `AppColors.secondary`
- Value: `(currentSectionIndex + 1) / totalSections` (includes category section if applicable)
- Below bar: `AppTextStyles.label` text — "Secao N de M" right-aligned

Replaces the dots row entirely. Do NOT keep both.

### 3. Submission Loading State

When "Enviar" is tapped and HTTP POST is in-flight:

- Disable the "Enviar" button (use `onPressed: null`)
- Replace button text with `SizedBox(width: 20, height: 20, child: CircularProgressIndicator(strokeWidth: 2, color: Colors.white))`
- Do not show a full-screen overlay — keep dialog visible

### 4. Submission Error Banner

When HTTP POST fails (network error or non-2xx response):

Structure: `Container` inserted between the section content and navigation row.
- Background: `Colors.red.shade50`
- Border: `Border.all(color: Colors.red.shade200)`
- Border radius: 8px
- Padding: 12px all sides
- Icon: `Icons.error_outline`, `Colors.red.shade600`, size 18
- Text: `AppTextStyles.bodyLarge.copyWith(color: Colors.red.shade700)` — see Copywriting section
- Below text: `TextButton` with label "Tentar novamente", `AppColors.primary` color
- Dismisses automatically when retry succeeds

### 5. Success Snackbar (existing pattern — extend)

Existing `ScaffoldMessenger` snackbar after successful submit:
- Keep current style: `AppColors.primary` background, white text
- Update copy — see Copywriting section

## Navigation and Interaction Contract

### Auto-advance: DISABLED for section-based layout

The current per-question auto-advance (`Future.delayed(200ms, _nextPage)`) applies only when there is a single question per page. In the new section layout, multiple questions appear on the same page — auto-advance is not applicable. Answering a Likert question on a section page does NOT advance to the next section.

### Navigation buttons

Each section page shows a button row at the bottom:
- Left: "Voltar" — `OutlinedButton`, `AppColors.primary` border and text, visible from section 1 onward (hidden on TCLE page, where "Nao Concordo" takes its place)
- Right: "Proximo" (sections 1–5) / "Finalizar secao" (section 6 for "Outro") / "Concluir" (last section for other categories) — `ElevatedButton`, `AppColors.primary` background, white text

Button dimensions:
- Height: 48px (vertical padding: 12px top+bottom — matches existing TCLE buttons)
- Border radius: 12px (matches existing TCLE buttons)
- Minimum width: fill available space via `Expanded`

### Section advancement gate

"Proximo" / "Concluir" is disabled (`onPressed: null`, visual opacity 0.5) while any question in the current section has no answer. It becomes active only when all questions in the section have a value.

Visual treatment for disabled state: `ElevatedButton.styleFrom` with `disabledBackgroundColor: AppColors.primary.withOpacity(0.4)`, `disabledForegroundColor: Colors.white.withOpacity(0.6)`.

### PageView physics

Keep `NeverScrollableScrollPhysics` — navigation is programmatic only via buttons. No swipe gestures.

### Animation on section advance

Keep existing `PageController.nextPage(duration: 300ms, curve: Curves.easeInOut)` and `previousPage(...)` for both directions.

### TCLE step

Unchanged — `_hasAcceptedTerms` flag gates entry to section pages. "Concordo" transitions to page 1 (SUS section). "Nao Concordo" closes dialog.

## Accessibility

- Minimum touch target: 44x44px — Likert circles are 45x45px, satisfies requirement
- All Semantics labels: add `Semantics(label: 'Opcao $value de 5', child: ...)` around each Likert GestureDetector
- Section header must be wrapped in `Semantics(header: true)`
- Error banner must include `Semantics(liveRegion: true)` so screen readers announce it on appearance
- "Tentar novamente" button: `Semantics(button: true, label: 'Tentar novamente enviar a avaliacao')`
- Contrast: all text on `AppColors.primary` (#1D3557) background uses white — passes WCAG AA (contrast ratio > 7:1)
