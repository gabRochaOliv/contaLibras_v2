## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Railway deploy → dashboard/ | Root Directory isolado; variáveis de ambiente configuradas por serviço |
| DASHBOARD_PASSWORD (Railway) → check_password() | Senha vai de env var Railway → os.environ → hmac.compare_digest — nunca em código |
| DATABASE_URL (Railway) → psycopg2 | Credencial de banco isolada por serviço Railway — não compartilhada com código-fonte |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
