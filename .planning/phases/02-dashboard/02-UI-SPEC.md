## Spacing Scale

> Streamlit does not expose raw CSS spacing tokens to the developer. Layout is declared as **column ratios** and **section order**, not px values. The following table maps conceptual spacing roles to Streamlit layout primitives.

| Token | Streamlit Primitive     | Usage                                              |
|-------|-------------------------|----------------------------------------------------|
| xs    | inline gap (default)    | Icon-to-label gap inside st.metric                |
| sm    | st.columns gap (default)| Gap between metric cards in header row            |
| md    | st.divider()            | Visual break between major dashboard sections      |
| lg    | `st.header()` + `st.divider()` | Section heading + separator before each chart |
| xl    | padding around sidebar  | Streamlit default sidebar padding (not configurable) |

**Column ratios (layout contract):**

| Section          | Column Declaration                  | Rationale                                       |
|------------------|-------------------------------------|-------------------------------------------------|
| Metric cards row | `st.columns(3)`                     | 3 equal cards: Total, Média Geral, Categorias   |
| Chart areas      | full width (no columns)             | Charts use `width="stretch"` for max readability|
| CSV download row | `st.columns([3, 1])` — button right | Label text left; download button right-aligned  |

Exceptions: Auth gate uses a single centered column via `st.columns([1, 2, 1])[1]` to keep the password input narrow and visually centered.

**Source:** RESEARCH.md Pattern 5 (chart width), Code Examples (cards), Claude's Discretion (layout order).

## Typography

> Streamlit inherits browser defaults via its system font stack. The following roles map to Streamlit text components.

| Role     | Streamlit Component           | Effective Size | Weight | Line Height |
|----------|-------------------------------|----------------|--------|-------------|
| Display  | `st.title()`                  | ~28px          | 700    | 1.2         |
| Heading  | `st.header()`                 | ~22px          | 600    | 1.3         |
| Body     | `st.write()` / `st.markdown()`| 16px           | 400    | 1.5         |
| Label    | `st.caption()` / metric delta | 14px           | 400    | 1.4         |

> `st.subheader()` is not part of the declared type scale. All section headings (including auth gate "Acesso Restrito") use `st.header()`.
> The 3 effective weights (700/600/400) are Streamlit-native browser defaults — not developer-configurable via Python. The executor cannot override them; these values are documented observations, not prescriptive declarations.

**Explicit text hierarchy for this phase:**

- Page title (`st.title`): "ContaLibras — Dashboard de Análise"
- Section headings (`st.header`): use exact labels defined in Copywriting Contract below
- Chart titles (Plotly `title=`): match section heading labels (pt-BR)
- Metric card labels (`st.metric` label param): 3-word max, capitalized

**Source:** Streamlit typography defaults (no override needed); headings from CONTEXT.md D-06 through D-11.

## Color

> Colors serve two purposes: Streamlit theme (surfaces/text) and Plotly chart palette (data series).

### Streamlit Theme Colors (60/30/10)

| Role             | Value     | Usage                                                      |
|------------------|-----------|------------------------------------------------------------|
| Dominant (60%)   | `#ffffff` | Page background, chart background, main content area       |
| Secondary (30%)  | `#f0f2f6` | Sidebar background, st.metric card background, auth form   |
| Accent (10%)     | `#1f77b4` | Primary CTA button (Exportar CSV), active sidebar filter, chart primary series |
| Destructive      | `#d62728` | Not used in this phase — no destructive actions exist      |

Accent reserved for:
1. "Exportar CSV" download button (primary CTA)
2. Active/selected state in sidebar `st.selectbox` (Streamlit renders via primaryColor)
3. First data series in all Plotly charts (Plotly default D3 palette: first color is `#1f77b4`)

**Source:** Streamlit config.toml theming; Plotly D3 default palette (ensures Streamlit accent matches chart primary series).

### Plotly Chart Palette (categorical series — D-08 comparativo)

> Used for the category comparison chart (grouped bars). One color per user category.

| Category              | Color     | Hex       |
|-----------------------|-----------|-----------|
| Pessoa surda          | blue      | `#1f77b4` |
| Professor             | orange    | `#ff7f0e` |
| Estudante             | green     | `#2ca02c` |
| Intérprete            | red       | `#d62728` |
| Outro                 | purple    | `#9467bd` |

**Implementation:** Pass `color_discrete_map` to `px.bar` — do not rely on automatic color assignment:

```python
COLOR_MAP = {
    "Pessoa surda": "#1f77b4",
    "Professor":    "#ff7f0e",
    "Estudante":    "#2ca02c",
    "Intérprete":   "#d62728",
    "Outro":        "#9467bd",
}
```

**Source:** Plotly D3 default palette (first 5 colors) — consistent with `primaryColor` in config.toml.

## Chart Contracts

> Each chart has a fixed specification. The executor must not deviate from these contracts.

### Chart 1 — Médias Likert por Questão (D-07)

| Property       | Value                                              |
|----------------|----------------------------------------------------|
| Type           | `px.bar` — vertical bars                          |
| x-axis         | Question label (e.g. "q4 — Gostaria de usar com frequência") |
| y-axis         | Mean value, range fixed `[1, 5]`                  |
| y-axis label   | "Média (1–5)"                                     |
| x-axis label   | "Questão"                                         |
| Title          | "Médias Likert por Questão"                        |
| Color grouping | By section (`color=section_col`) using color sequence: `["#1f77b4","#ff7f0e","#2ca02c","#d62728","#9467bd","#8c564b"]` |
| Hover          | Show full question text + mean value (2 decimals) |
| Reference line | Horizontal dotted line at y=3 (neutral midpoint)  |
| Width          | `width="stretch"`                                 |
| Height         | 500px via `fig.update_layout(height=500)`         |

### Chart 2 — Comparativo por Categoria (D-08)

| Property       | Value                                              |
|----------------|----------------------------------------------------|
| Type           | `px.bar` — grouped bars (`barmode="group"`)       |
| x-axis         | Section name (6 sections)                         |
| y-axis         | Mean per section, range fixed `[1, 5]`            |
| y-axis label   | "Média (1–5)"                                     |
| x-axis label   | "Seção"                                           |
| Title          | "Comparativo por Categoria de Usuário"             |
| Color          | `color="categoria"`, `color_discrete_map=COLOR_MAP` (5 categories) |
| Hover          | Category + section + mean (2 decimals)            |
| Width          | `width="stretch"`                                 |
| Height         | 450px via `fig.update_layout(height=450)`         |

### Chart 3 — Timeline de Coleta (D-09)

| Property       | Value                                              |
|----------------|----------------------------------------------------|
| Type           | `px.line` — with `markers=True`                  |
| x-axis         | Date (grouped by day: `df["criado_em"].dt.date`)  |
| y-axis         | Count of responses                                |
| y-axis label   | "Respostas"                                       |
| x-axis label   | "Data"                                            |
| Title          | "Volume de Coleta por Dia"                        |
| Color          | `#1f77b4` (single series — no category split)    |
| Markers        | `markers=True` — points at each day               |
| Width          | `width="stretch"`                                 |

| Timezone       | Convert `criado_em` to `America/Sao_Paulo` before grouping |

## Interaction States

> Every interactive element must handle all states below.

### Auth Gate

| State         | Visual                                                   |
|---------------|----------------------------------------------------------|
| Idle          | Password input visible, button "Acessar Dashboard" enabled |
| Error         | `st.error("Senha incorreta. Tente novamente.")` below input |
| Authenticated | Auth gate hidden; full dashboard rendered               |

### Sidebar Filter

| State              | Visual                                                |
|--------------------|-------------------------------------------------------|
| Default            | selectbox shows "Todos" — all data included           |
| Category selected  | selectbox shows category name; all 3 charts re-render with filtered df |
| No data for filter | st.warning shown (see Empty State below)              |

### Download Button

| State      | Visual                                                         |
|------------|----------------------------------------------------------------|
| Idle       | Blue button "Exportar CSV" (Streamlit primaryColor)           |
| Processing | Streamlit spinner (automatic during CSV generation)           |
| Downloaded | Browser default file download dialog; button returns to idle  |

## Empty and Error States

### Empty State (no data after filter)

- **Trigger:** `len(df_filtered) == 0`
- **Component:** `st.warning("Nenhuma resposta encontrada para o filtro selecionado. Altere a categoria ou aguarde novas respostas.")`
- **Placement:** Immediately below the sidebar filter, before metric cards
- **Charts:** Do NOT render charts when df is empty — use `st.stop()` after warning or conditional render

### Empty State (no data at all — zero rows in DB)

- **Trigger:** `len(df_raw) == 0`
- **Component:** `st.info("Nenhuma resposta coletada ainda. Os gráficos serão exibidos quando houver dados.")`
- **Placement:** After metric cards (cards still render with zeros)

### Database Error State

- **Trigger:** `psycopg2.OperationalError` or any exception in `load_data()`
- **Component:** `st.error("Erro ao carregar os dados. Verifique a conexão com o banco de dados e recarregue a página.")`
- **Placement:** Top of main content area, after auth gate passes
- **Behavior:** `st.stop()` after error message — do not render partial content

**Source:** RESEARCH.md Pitfall 1 (SSL error), Pitfall 2 (cache TTL); Claude's Discretion (empty state placement).
